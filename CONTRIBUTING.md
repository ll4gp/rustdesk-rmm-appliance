# Contributing to RustDesk RMM Plug-In Appliance

Thank you for your interest in contributing!

## Ways to Contribute
1. **Report Bugs or Suggest Features**: Open a GitHub Issue with your OS, Docker version, and deployment mode (`Plug-In` vs. `Full-Stack`).
2. **Share Built-In RMM Scripts**: Pull requests adding useful cross-platform diagnostic or maintenance scripts to `server/database.js` and `server/routes/agent.js` are welcome.
3. **Submit Pull Requests**:
   - Fork the repository and create a feature branch (`git checkout -b feature/my-feature`).
   - Verify the frontend builds cleanly (`npm run build`).
   - Open a Pull Request against `main`.
